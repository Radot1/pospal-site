Υπεύθυνος επεξεργασίας και αδειοδότης: ο ανωτέρω πάροχος. Η POSPal υπάγεται επί του παρόντος στο ελληνικό καθεστώς απαλλαγής ΦΠΑ μικρών επιχειρήσεων. Δεν προστίθεται ΦΠΑ στη συνδρομή. Επικοινωνία: support@pospal.gr.

1. Πεδίο εφαρμογής και ρόλοι

Η παρούσα καλύπτει τον ιστότοπο pospal.gr, την εφαρμογή Windows, τη δοκιμή, την αδειοδότηση και συνδρομή, τη χρέωση μέσω Stripe, τη συλλογή φορολογικού προφίλ, τις συναλλακτικές επικοινωνίες, τα δημόσια Μενού Πελατών, τα διαγνωστικά και τις αναφορές υποστήριξης.

Για τα δεδομένα που ο έμπορος εισάγει στην εφαρμογή για τη δική του λειτουργία —όπως παραγγελίες, σημειώσεις ή στοιχεία προσωπικού/πελατών— ο έμπορος είναι ο υπεύθυνος επεξεργασίας. Το POSPal ενεργεί ως εργαλείο και, μόνο όταν τέτοια δεδομένα διαβιβάζονται σε λειτουργία cloud για λογαριασμό του εμπόρου, ως εκτελών την επεξεργασία σύμφωνα με το DPA.

2. Δεδομένα που παραμένουν κυρίως τοπικά

Μενού, παραγγελίες, αποδείξεις λειτουργίας, ρυθμίσεις καταστήματος, εκτυπωτές, τοπικά αρχεία καταγραφής και αντίγραφα ασφαλείας αποθηκεύονται κατά κύριο λόγο στον υπολογιστή του εμπόρου. Η εφαρμογή μπορεί να εξυπηρετεί εξουσιοδοτημένες συσκευές στο ίδιο τοπικό δίκτυο. Ο έμπορος είναι υπεύθυνος για τη νόμιμη καταχώριση, την ασφάλεια, τα αντίγραφα ασφαλείας και τη διαγραφή αυτών των τοπικών δεδομένων.

4. Πληρωμές και φορολογικά παραστατικά

Η Stripe συλλέγει τα στοιχεία κάρτας και χρέωσης στο δικό της checkout. Το POSPal δεν αποθηκεύει πλήρεις αριθμούς καρτών. Ο τραπεζικός λογαριασμός στον οποίο ο πάροχος λαμβάνει τις αποδόσεις της Stripe δεν αποτελεί επεξεργαστή πληρωμών πελατών του POSPal.

Το φορολογικό παραστατικό εκδίδεται χωριστά μέσω εξωτερικού ελληνικού παρόχου ηλεκτρονικής τιμολόγησης/myDATA. Η ταυτότητα, ο ρόλος, η παράδοση και η ευθύνη myDATA του παρόχου εκκρεμούν. Δεν επιτρέπεται διαβίβαση φορολογικού προφίλ στον πάροχο μέχρι να καταχωρισθούν τα στοιχεία αυτά.

5. Ιστότοπος, cookies και ενσωματωμένο περιεχόμενο

Ο ιστότοπος pospal.gr φιλοξενείται στο GitHub Pages. Οι λειτουργίες αδειοδότησης και δεδομένων της εφαρμογής παρέχονται χωριστά μέσω Cloudflare Workers/D1/R2, ενώ το δημόσιο frontend των Μενού Πελατών στο menu.pospal.gr παραδίδεται μέσω Cloudflare Pages. Google Analytics 4, Google Ads και Microsoft Clarity φορτώνονται στο pospal.gr μόνο μετά την αντίστοιχη θετική επιλογή. Τα βίντεο οδηγών χρησιμοποιούν τη λειτουργία ενισχυμένου απορρήτου του YouTube και δεν συνδέονται με το YouTube πριν δοθεί συγκατάθεση για εξωτερικά μέσα. Η προτίμηση αποθηκεύεται τοπικά και ζητείται ξανά μετά από έξι μήνες. Λεπτομέρειες βρίσκονται στην Πολιτική Cookies.

6. GitHub: δημόσιες αναφορές και ενημερώσεις

Οι αναφορές που αποστέλλονται από την εφαρμογή δημιουργούν δημόσιο issue στο GitHub και μπορούν να αντιγραφούν από μηχανές αναζήτησης ή caches. Το POSPal επιχειρεί αυτοματοποιημένη απόκρυψη κοινών ευαίσθητων τιμών, αλλά ο χρήστης δεν πρέπει να συμπεριλαμβάνει προσωπικά, εμπιστευτικά ή στοιχεία πληρωμών. Η διαγραφή αργότερα δεν εγγυάται διαγραφή αντιγράφων τρίτων. Η συσκευασμένη εφαρμογή ελέγχει και λαμβάνει ενημερώσεις από δημόσια αποθετήρια/artifacts· το GitHub λαμβάνει συνήθη δεδομένα αιτήματος όπως IP, user agent, ζητούμενο αρχείο και χρόνο.

7. Αποδέκτες και διαβιβάσεις

Ανά λειτουργία χρησιμοποιούνται GitHub Pages για το pospal.gr, Cloudflare Workers/D1/R2/Pages για backend και Μενού Πελατών, Stripe, Resend, GitHub, Google/YouTube και Microsoft/Clarity. Ο ενημερωμένος κατάλογος, ο ρόλος, η τοποθεσία και οι πληροφορίες για τον μηχανισμό διεθνούς διαβίβασης κάθε παρόχου βρίσκονται στους Υπεργολάβους Επεξεργασίας. Η επαλήθευση των τρεχόντων συμβατικών μηχανισμών και της εφαρμογής τους στον συγκεκριμένο λογαριασμό για τυχόν διαβιβάσεις εκτός ΕΟΧ εκκρεμεί.

9. Πηγές, υποχρεωτικά στοιχεία και αυτοματοποιημένοι κανόνες

Λαμβάνουμε δεδομένα απευθείας από εσάς και την εφαρμογή, αυτόματα από συσκευές/αιτήματα και από Stripe, Resend, Cloudflare ή GitHub για κατάσταση συναλλαγής, παράδοσης, φιλοξενίας και υποστήριξης. Τα στοιχεία checkout, επικοινωνίας και φορολογικού προφίλ που επισημαίνονται ως υποχρεωτικά απαιτούνται για πληρωμένη συνδρομή και νόμιμο παραστατικό· χωρίς αυτά δεν ολοκληρώνεται η αντίστοιχη υπηρεσία. Η δημοσίευση μενού και η αποστολή αναφοράς υποστήριξης είναι επιλογές του εμπόρου.

Αυτοματοποιημένοι κανόνες μπορεί να απορρίψουν επαναλαμβανόμενη δοκιμή, να σημάνουν παραποίηση, να περιορίσουν συνεδρία/άδεια ή να αναστείλουν χρήση μετά από αποτυχία που αναφέρει η Stripe. Δεν χρησιμοποιούμε δεδομένα εφαρμογής για διαφημιστική κατάρτιση προφίλ. Μπορείτε να ζητήσετε ανθρώπινο έλεγχο στο support@pospal.gr.

10. Δικαιώματα

Μπορείτε να ζητήσετε πρόσβαση, διόρθωση, διαγραφή, περιορισμό, φορητότητα ή να αντιταχθείτε, όπου εφαρμόζεται, και να ανακαλέσετε συγκατάθεση χωρίς να θίγεται η προηγούμενη επεξεργασία. Επικοινωνήστε στο support@pospal.gr. Μπορεί να ζητηθεί εύλογη επιβεβαίωση ταυτότητας· απαντούμε κατά κανόνα εντός ενός μήνα, με τις νόμιμες εξαιρέσεις. Μπορείτε επίσης να υποβάλετε καταγγελία στην Ελληνική Αρχή Προστασίας Δεδομένων Προσωπικού Χαρακτήρα: https://www.dpa.gr/.

11. Ασφάλεια, αλλαγές και παιδιά

Χρησιμοποιούμε HTTPS, περιορισμούς πρόσβασης, κατακερματισμό επιλεγμένων αναγνωριστικών, ελαχιστοποίηση/redaction και μέτρα ανάλογα με τον κίνδυνο. Κανένα σύστημα δεν είναι απολύτως ασφαλές. Το POSPal είναι επαγγελματικό προϊόν και δεν απευθύνεται σε παιδιά. Οι ουσιώδεις αλλαγές θα φέρουν νέα ημερομηνία αναθεώρησης και, όπου απαιτείται, κατάλληλη ενημέρωση.
