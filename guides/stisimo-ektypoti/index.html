Νέο
Το βίντεο του Οδηγού 0 θα εμφανιστεί εδώ

Μόλις προσθέσεις το YouTube URL, η σελίδα θα το ενσωματώνει αυτόματα στο player.

Προσθήκη URL: ρύθμισε το `data-video-url` στο στοιχείο `` ή άνοιξε τη σελίδα με `?yt=YOUTUBE_URL`.

Τι θα μάθεις σε 30''

Πώς να ετοιμάσεις εκτυπωτή στα Windows και να επιβεβαιώσεις test print πριν την εγκατάσταση POSPal.

Διάρκεια

8-12 λεπτά

Πριν ξεκινήσεις

Εκτυπωτής συνδεδεμένος, χαρτί διαθέσιμο, πρόσβαση σε Windows ρυθμίσεις.

Αν κάτι δεν δουλέψει: έλεγξε πρώτα σύνδεση/ουρά εκτύπωσης. Αν το πρόβλημα παραμένει, στείλε screenshot στο support πριν προχωρήσεις.
