# Homepage Prototype

Throwaway prototype for comparing three structurally different POSPal homepage directions.

Run from the repository root:

```powershell
python -m http.server 4173
```

Open:

- `http://localhost:4173/prototype/homepage/?variant=A`
- `http://localhost:4173/prototype/homepage/?variant=B`
- `http://localhost:4173/prototype/homepage/?variant=C`

Use the bottom switcher or the left/right arrow keys to move between variants.

The prototype is `noindex`, is not linked from the production site, and should be deleted or absorbed after a direction is selected.
