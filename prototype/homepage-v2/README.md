# Living Order Route Prototype

High-fidelity homepage prototype selected through the POSPal redesign shape process.

## Boundaries

- Prototype only: `noindex`, absent from `sitemap.xml`, and isolated from production pages.
- Uses real approved Greek copy and destinations.
- Product screens, QR code, and kitchen output are labelled capture slots until authentic assets are available.
- Core content and links work without JavaScript.
- JavaScript controls only the signature order-route animation and its pause state.

## Visual Contract

- North star: `docs/redesign/probes/homepage-direction-board.png`, direction C.
- Palette: `docs/redesign/probes/living-order-route-palette.png`.
- Light opening, deep-forest operational folds, POSPal green route/action color, amber offline signal.
- One signature story: device leaves Wi-Fi, stores the order, reconnects, synchronizes, and routes to kitchen.

## Deferred Assets

- Authentic Windows application capture.
- Authentic staff-device capture.
- Authentic kitchen/order-output capture.
- Published controlled QR-menu sample and real scannable QR code.
