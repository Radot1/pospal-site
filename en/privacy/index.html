1. Scope and roles

This notice covers pospal.gr, the Windows app, trial, licensing and subscription, Stripe billing, fiscal-profile collection, transactional communications, public Customer Menus, diagnostics, and support reporting.

For operational data the merchant enters for its own purposes—such as orders, notes, or staff/customer details—the merchant is controller. POSPal is a tool and acts as processor only where merchant-controlled data is sent to a cloud feature on the merchant's behalf, subject to the DPA.

2. Predominantly local data

Menus, orders, operational receipts, store settings, printer configuration, local logs, and backups are stored predominantly on the merchant's computer. The app may serve authorised devices on the same LAN. The merchant is responsible for lawful entry, security, backup, retention, and deletion of this local data.

4. Payments and fiscal documents

Stripe collects card and billing data in its checkout; POSPal does not store full card numbers. The bank account to which the provider receives Stripe payouts is not a POSPal customer-payment processor.

Fiscal documents are issued separately through an external Greek e-invoicing/myDATA provider. Provider identity, role, delivery, and myDATA responsibility remain pending; publication/transfer is blocked.

5. Website and trackers

The pospal.gr website is hosted on GitHub Pages. App licensing and data functions are separately provided through Cloudflare Workers/D1/R2, while the public Customer Menu frontend at menu.pospal.gr is delivered through Cloudflare Pages. Google Analytics 4, Google Ads, and Microsoft Clarity load on pospal.gr only after the matching positive choice. Guide videos use YouTube privacy-enhanced mode and do not connect to YouTube before external-media consent. The preference is stored locally and requested again after six months. Details are in the Cookie Policy.

6. GitHub: public reports and updates

In-app reports create a public GitHub issue and may be copied by search engines or caches. POSPal attempts automatic redaction, but users must not include personal, confidential, or payment data. Later deletion cannot guarantee removal of third-party copies. The packaged app checks for and downloads updates from public repositories/artifacts; GitHub receives ordinary request data such as IP, user agent, requested file, and time.
